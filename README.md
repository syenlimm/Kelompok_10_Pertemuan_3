# Kantin 88 Untar

Website satu halaman untuk Kantin 88 Untar, kantin yang berada persis di sebelah Kampus Universitas Tarumanagara di Tomang, Jakarta Barat. Dibuat pakai HTML dan CSS biasa, dengan warna merah dan emas.

## Bagian di halaman

- Hero dengan nama kantin, jam buka, dan tombol ke lokasi
- Sedikit cerita tentang kantinnya
- Menu per kategori (Ayam, Sayur & Tahu Tempe, Nasi & Pelengkap, Minuman) beserta harga
- Alamat, jam buka, kontak, dan peta lokasi

## Cara pakai

Tidak perlu install apa-apa.

1. Download atau clone repo ini
2. Pastikan `kantin-88-untar.html` dan `style.css` ada di folder yang sama
3. Buka `kantin-88-untar.html` di browser

Kalau mau dipublikasikan, tinggal upload kedua file itu ke GitHub Pages, Netlify, atau layanan hosting statis lainnya.

### Lewat GitHub Pages

1. Push repo ini ke GitHub
2. Masuk ke Settings → Pages
3. Pilih branch `main`, folder root
4. Tunggu beberapa menit, websitenya akan aktif di `https://<username>.github.io/<nama-repo>/kantin-88-untar.html`
