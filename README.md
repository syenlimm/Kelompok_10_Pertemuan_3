# Kantin 88 Untar

Website satu halaman (single-page) untuk **Kantin 88 Untar** — kantin legendaris sejak 1989 di samping Kampus Universitas Tarumanagara, Tomang, Jakarta Barat. Dibangun dengan HTML dan CSS murni, bertema merah maroon dan emas yang terinspirasi nuansa restoran klasik dan makna keberuntungan pada angka "88".

## Preview

Buka `kantin-88-untar.html` di browser untuk melihat websitenya secara langsung.

## Struktur File

```
.
├── kantin-88-untar.html   # Struktur & konten halaman
├── style.css              # Semua styling (warna, tipografi, layout, responsive)
└── README.md
```

## Isi Halaman

- **Hero** — nama kantin, tagline, jam buka, dan tombol arah ke lokasi
- **Tentang** — cerita singkat kantin dan beberapa statistik
- **Menu** — daftar menu per kategori (Ayam, Sayur & Tahu Tempe, Nasi & Pelengkap, Minuman) lengkap dengan harga
- **Lokasi** — alamat, jam operasional, kontak, dan peta Google Maps tertanam

## Cara Menjalankan

Tidak memerlukan proses build atau instalasi apa pun. Cukup:

1. Clone atau unduh repository ini
2. Pastikan `kantin-88-untar.html` dan `style.css` berada dalam satu folder yang sama
3. Buka `kantin-88-untar.html` langsung di browser

Untuk menjalankan sebagai website publik, unggah kedua file ke layanan hosting statis seperti **GitHub Pages**, Netlify, atau Vercel.

### Menjalankan lewat GitHub Pages

1. Push repository ini ke GitHub
2. Buka **Settings → Pages**
3. Pilih branch `main` dan folder root (`/`)
4. Simpan — website akan aktif di `https://<username>.github.io/<nama-repo>/kantin-88-untar.html`

## Teknologi

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Google Fonts — [Fraunces](https://fonts.google.com/specimen/Fraunces) & [Work Sans](https://fonts.google.com/specimen/Work+Sans)
- Google Maps Embed (tanpa API key)

## Catatan

Daftar menu dan harga pada website ini adalah estimasi dan dapat disesuaikan langsung di dalam `kantin-88-untar.html` pada bagian `<section class="menu">`. Harap verifikasi harga terbaru langsung di lokasi kantin.

## Lisensi

Bebas digunakan dan dimodifikasi untuk keperluan Kantin 88 Untar.
